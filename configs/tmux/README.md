# tmux

**The long-running exception.** herdr panes survive *detach*, but a herdr
*server restart* restores layout and agent conversations — not an arbitrary
running process. A three-day training run therefore belongs in tmux underneath a
herdr pane.

Text-only status line (no Nerd Font glyphs) so it renders identically in Ghostty
and Termius. `escape-time 0` keeps modal TUIs responsive; `extended-keys on`
lets ctrl+enter reach agents.
